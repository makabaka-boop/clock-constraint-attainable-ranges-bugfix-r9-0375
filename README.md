# 时钟偏移校正复核（Go API + Svelte）

复核一份模拟的同步调用链：2～8 个服务、至多 100 个 span。每个 span 记录
所在服务、父 span、以及该服务**本地时钟**上的整数开始/结束时刻。每个服务
有一个允许的整数时钟偏移区间，其中恰好一个服务锚定为 `[0,0]`。

## 模型

记 `x[s]` 为服务 `s` 的时钟偏移（整数）。校正后每个子调用必须完整落在父
调用区间内，即对每条父子关系（子 span `c` 在服务 `cs`，父 span `p` 在服务
`ps`）：

```
c.start + x[cs] >= p.start + x[ps]   <=>   x[ps] - x[cs] <= c.start - p.start
c.end   + x[cs] <= p.end   + x[ps]   <=>   x[cs] - x[ps] <= p.end   - c.end
```

加上偏移界 `lo <= x[s] <= hi`（经固定为 0 的辅助零点节点表示），全部化为
**差分约束**：

- **可行性**：Bellman-Ford 检测负环。若无解，返回的**矛盾环**逐边携带
  来源（偏移界 / 某条父子约束的起点侧或终点侧），前端只展示证据，
  **不绘制伪造的校正时间线**。
- **字典序最小解**：按服务 ID 升序逐个固定变量。固定 `x_j = v_j` 等价于
  加入边 `j -> 0`（权 `-v_j`），故在已固定集合 `F` 下
  `x_k = max_{j in F ∪ {0}} (v_j - dist(k, j))`（`dist` 为全源最短路，
  Floyd-Warshall）。差分约束系统单变量可行值构成区间，取最小值后系统
  仍可满足，贪心成立。

成功时响应中同时携带：各服务偏移、每个 span 的校正时刻（供绘制时间线）、
每条父子约束的起点/终点余量（均 ≥ 0，为 0 表示紧约束）。

## 页面行为

- 编辑偏移界或 span 后，输入快照与求解时快照失配，**旧结果立即失效**
  （时间线与余量隐藏，提示重新求解）。
- 求解成功：从**同一次响应**绘制校正时间线（按服务分行、行内泳道防重叠、
  父子连线）并列出每条父子约束的余量。
- 无解：仅展示矛盾环（每条边 = 一条真实输入约束 + 权重，总权重为负）。

## 运行

```bash
# 后端（内嵌已构建的前端；web/dist 未构建时提供占位页）
go run .                 # 监听 :8080，ADDR 环境变量可覆盖

# 前端开发（代理 /api 到 :8080）
cd web && npm install && npm run dev

# 前端构建（产物嵌入 Go 二进制）
cd web && npm run build
```

  API 层（无解响应不含任何时间线字段、未知字段拒绝、示例自洽）。


## 时刻差可行范围
打开 `/ranges`，每个查询指定左/右 span 的 start 或 end，计算校正后右时刻减左时刻的全局最小及最大可能值。
端点在**同一张完整差分约束图**（全部偏移界 + 全部父子约束）上用全源最短路求出：若左右时刻
分属服务 a、b、本地值为 l、r，则

```
max D = (r-l) + dist(a,b)
min D = (r-l) - dist(b,a)     （dist 为全源最短路，含零点节点）
```

每个端点附一份完整偏移见证 `x[v] = dist(src,v) - dist(src,0)`（取 src=a 达最大、src=b 达最小），
见证在返回前经独立复核：满足全部约束且目标量确实等于所声明端点；两份见证不要求相同。
结果保持查询 ID 与请求顺序，至多 16 个且 ID 唯一。相同服务的两个时刻共享同一偏移
（dist(s,s)=0，范围退化为单点，不展示虚构变化），允许负差值和相等时刻。
输入本身先经 `Validate`，再校验查询数量/ID/时刻引用；任一非法整份拒绝（400 + 错误列表），
已通过但无解时只返回原矛盾环，不展示可行范围。页面编辑使旧范围和下载证据立即失效
（revision 令牌 + 按钮门禁，逻辑在 `web/src/lib/ranges-state.js` 并有 vitest 覆盖），
原字典序求解继续可用。

### 时刻差复核的可复验用例
- `TestRangesAgainstBruteForce`：3000 组随机小用例，穷举**全部**界内整数偏移向量，
  逐一计算每个查询的真实 min/max 与求解器比对；并独立核验两份见证界内、满足全部
  父子约束、锚点为 0，且目标量恰好等于声明端点。
- 定向用例：父子约束把服务界给出的宽松区间收紧、同服务时刻差为单点、负差值与
  终点侧约束、查询 ID/顺序保留、无矛盾输入时只返回环。
- API 层：非法时刻引用/时刻类型/重复或空 ID/超量/未知字段/尾随内容整份 400，
  无解响应不含 ranges 与任何时间线字段。


启动：先在 web 执行 npm ci 和 npm run build，再从项目根目录 go run .。新增时刻差复核页位于 /ranges。
