# 时钟偏移校正复核（Go API + Svelte）

复核一份模拟的同步调用链：2～8 个服务、至多 100 个 span。每个 span 记录
所在服务、父 span、以及该服务**本地时钟**上的整数开始/结束时刻。每个服务
有一个允许的整数时钟偏移区间，其中恰好一个服务锚定为 `[0,0]`。

## 模型

记 `x[s]` 为服务 `s` 的时钟偏移（整数）。校正后每个子调用必须完整落在父
调用区间内，即对每条父子关系（子 span `c` 在服务 `cs`，父 span `p` 在服务
`ps`）：

```
c.start + x[cs] >= p.start + x[ps]   <=>   x[ps] - x[cs] <= c.start - p.start
c.end   + x[cs] <= p.end   + x[ps]   <=>   x[cs] - x[ps] <= p.end   - c.end
```

加上偏移界 `lo <= x[s] <= hi`（经固定为 0 的辅助零点节点表示），全部化为
**差分约束**：

- **可行性**：Bellman-Ford 检测负环。若无解，返回的**矛盾环**逐边携带
  来源（偏移界 / 某条父子约束的起点侧或终点侧），前端只展示证据，
  **不绘制伪造的校正时间线**。
- **字典序最小解**：按服务 ID 升序逐个固定变量。固定 `x_j = v_j` 等价于
  加入边 `j -> 0`（权 `-v_j`），故在已固定集合 `F` 下
  `x_k = max_{j in F ∪ {0}} (v_j - dist(k, j))`（`dist` 为全源最短路，
  Floyd-Warshall）。差分约束系统单变量可行值构成区间，取最小值后系统
  仍可满足，贪心成立。

成功时响应中同时携带：各服务偏移、每个 span 的校正时刻（供绘制时间线）、
每条父子约束的起点/终点余量（均 ≥ 0，为 0 表示紧约束）。

## 页面行为

- 编辑偏移界或 span 后，输入快照与求解时快照失配，**旧结果立即失效**
  （时间线与余量隐藏，提示重新求解）。
- 求解成功：从**同一次响应**绘制校正时间线（按服务分行、行内泳道防重叠、
  父子连线）并列出每条父子约束的余量。
- 无解：仅展示矛盾环（每条边 = 一条真实输入约束 + 权重，总权重为负）。

## 运行

```bash
# 后端（内嵌已构建的前端；web/dist 未构建时提供占位页）
go run .                 # 监听 :8080，ADDR 环境变量可覆盖

# 前端开发（代理 /api 到 :8080）
cd web && npm install && npm run dev

# 前端构建（产物嵌入 Go 二进制）
cd web && npm run build
```

## 测试

```bash
go test ./...            # 求解器 + API
cd web && npm test       # 结果失效逻辑 + 范围页复验逻辑
```

- **对拍**：`internal/solver` 以固定种子生成数千组小用例（2～3 服务、
  窄区间），与穷举全部整数偏移向量的暴力解逐一比对可行性结论与字典序
  最小解；范围复核同样逐查询与穷举出的真实最小/最大差值对拍。
- **无解证据逐边核验**：对每组无解用例，从原始输入**独立重算**环上每条
  边的端点与权重，验证边真实存在、首尾相接成环、总权重为负。
- **范围见证逐份核验**：每份 min/max 见证独立检查覆盖全部服务、落在偏移
  界内、满足全部父子约束，且代入后差值恰好等于声明端点。
- 另覆盖：余量精确性与非负性、字典序方向、自环/过零点环、同服务差值恒定、
  负差值与相等时刻、传递约束收紧、查询校验表（非法引用/重复/超限整份拒绝）、
  输入校验表、API 层（无解响应不含任何时间线与范围字段、未知字段拒绝、
  示例自洽、范围页托管）。


## 时刻差可行范围
打开 `/ranges`，每个查询指定左/右 span 的 start 或 end，计算校正后右时刻减左时刻的全局最小及最大可能值。
所有偏移仍必须同时满足原界限与全部父子调用约束：记左/右时刻所在服务为 `a`、`b`，本地时刻为 `l`、`r`，
则差值 `D = (r-l) + (x[b]-x[a])`，而 `x[b]-x[a]` 的最紧上界即差分约束图上的最短路 `dist(a,b)`，
故 `max = (r-l) + dist(a,b)`、`min = (r-l) - dist(b,a)`。
两个端点分别附一份**真正达到该值**的完整偏移见证（覆盖全部服务、落在各自偏移界内、满足每一条父子约束；
构造方法：加入边 `b->a` 权 `-dist(a,b)` 后取零点最短路），不要求两端点来自同一个见证。
结果保持查询 ID 与请求顺序，至多 16 个且 ID 唯一。相同服务的两个时刻共享同一偏移，差值退化为常数
（min == max），允许负差值和相等时刻。
无解时只返回原矛盾环，不展示可行范围；任一查询无效（未知 span、非法时刻类型、ID 重复或为空、数量超限）
或输入非法，整份拒绝。页面编辑使旧范围和下载证据立即失效；页面对每份见证独立复验
（覆盖性、偏移界、父子约束、是否达到端点）。原字典序求解继续可用。

启动：先在 web 执行 npm ci 和 npm run build，再从项目根目录 go run .。时刻差复核页位于 /ranges，
由前端构建产物提供（vite 多页构建：index.html + ranges.html）。
